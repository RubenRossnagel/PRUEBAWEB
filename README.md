# Mi Aplicación Web

Una aplicación web sencilla creada con HTML, CSS y JavaScript.

## Características

- Diseño moderno y responsive
- Interfaz interactiva
- Código limpio y organizado

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Cómo usar

1. Abre el archivo `index.html` en tu navegador
2. Haz clic en el botón "¡Saludar!" para ver el mensaje
